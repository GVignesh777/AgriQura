## 🛠️ Tech Stack
- **Runtime:** Node.js
- **Framework:** Express 4
- **Database:** MongoDB Atlas + Mongoose
- **AI Acceleration:** Groq SDK (Llama 3)
- **Security:** Helmet, Express Rate Limit, JWT, CORS
- **Email Service:** EmailJS / Nodemailer
- **Default Port:** `5000`
